# Validation evidence

Development validation date: 2026-11-04. Scope is the implementation and generated synthetic/demo packages, not real-world universal APK conversion.

## Automated tests

The unittest suite covers plain and binary Android manifests (both UTF-8 and UTF-16 string pools), binary-manifest end-to-end conversion, native-app port requirement, candidate selection, arbitrary asset and bridge-call preservation, optional acknowledgements, web directory input, output preservation, deterministic package construction, package tampering, metadata rules, path traversal, file/directory collisions, case collisions, symlinks, size limits, split/bundle rejection and CLI flows.

The desktop UI was constructed successfully with Tk on the Windows development host. The version 0.2.0 smoke test selects a generated APK, waits for automatic analysis and defaults, invokes the Convert button, waits for completion, and verifies the resulting IPK. It passed with Python 3.15 and 3.13 on the development host. Four additional tests cover automatic metadata, stable TV identity across APK updates, unusual labels/versions and output collision avoidance. The desktop build workflow also runs this path inside the bundled Windows executable before publishing it. These checks do not establish full interactive UI coverage or TV behavior.

## LG CLI cross-check

Installed development tooling: `@webos-tools/cli@3.2.6`, Node 24.22.1. The official `ares-package -i` successfully inspected a builtin-generated demo IPK. Official `ares-package <app> -o <output> --no-minify` also successfully repackaged the generated app, and the toolkit's verifier accepted the official IPK. The automated repeatable check is `tools/check_official.py --cli-js <path-to-ares-package.js>`; CI runs the same check.

The CLI identified a missing `requiredACG` declaration during initial validation. Generation now defaults it to `[]`, preserving an existing web export's declaration when present. Apps calling Luna APIs must declare the actual required groups according to [LG's ACG guide](https://webostv.developer.lge.com/develop/guides/acg-guide).

## Outstanding runtime validation

Version 0.4.0 adds eight tests for the no-entry content-viewer path, literal/escaped content handling, namespace collisions, binary XML classification, bounded text previews, resource preservation and avoiding binary-resource heuristic false positives (51 total). The GUI smoke test covers three cases: existing HTML, browser JavaScript without HTML, and a native-only APK. A real Reezn resource-viewer package was generated and structurally checked separately; LG's CLI successfully inspected it with `main: index.html`. It retained 2357 resource files, including 1105 image files, 21 readable text files and one dependent HTML component; no embedded audio/video files were found by extension. `tools/check_viewer.js` successfully exercised its generated viewer behavior in a minimal DOM, including search, filtering, image selection, pagination and leaving the search input with D-pad Down. This is not an actual browser or TV test.

No LG TV was connected. No Android APK was executed, no real third-party app was converted into a working equivalent, and no claim of UI, API or feature parity has been verified. TV installation, remote navigation, browser engine support, authentication, DRM, codecs, permissions and store eligibility remain device/app-specific acceptance work.

Version 0.3.0 adds 11 tests for alternate HTML locations, generated HTML around browser JavaScript, module entries, stylesheet/mount recovery, unchanged assets and Android-dependent component handling (43 total tests). The source GUI smoke test now runs both an APK with HTML and a browser-JS APK with no HTML. The Windows build runs the same test inside the frozen executable. A generated no-index demo is included under `examples/no-index-web/`. An attempted local browser preview could not reach the sandbox loopback HTTP server, so interactive browser behavior was not verified in this session; package and GUI workflow checks do not imply browser/TV acceptance.
